# Demo / viva talking points

1. **Why this project?** It joins system telemetry, history, explainable diagnostics and defensive security indicators.
2. **Why psutil?** It provides cross-platform process and resource information.
3. **Why FastAPI?** It exposes typed REST endpoints and interactive API docs.
4. **Why SQLite?** Local persistence without a separate database server.
5. **What is a sustained rule?** It checks a rolling set of consecutive samples rather than reacting only to one spike.
6. **Does a suspicious process name prove malware?** No; names are heuristics and need independent verification.
7. **What does file integrity detect?** Content changes relative to a SHA-256 baseline, not whether the change was malicious.
8. **What is a CPE?** A standardized product identifier used to query vulnerability data; inaccurate product/version identifiers can make results incomplete.
9. **What does WSL2 measure?** The Linux environment running the backend, not necessarily the Windows host.
10. **How would you extend the project?** Authentication, alert delivery, improved baselines, richer host audit logs and asset inventory.
