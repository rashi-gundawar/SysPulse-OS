# SysPulse OS — System Resource Monitoring Suite

SysPulse OS is a system monitoring and educational simulation platform designed to explore operating system concepts through an interactive dashboard.

### Features
- **System Monitoring:** CPU, memory, and process insights.
- **CPU Scheduling:** Visualize scheduling algorithms.
- **Memory Management:** Explore memory allocation and page replacement.
- **Deadlock & Synchronization:** Simulate resource allocation, deadlocks, and synchronization mechanisms.
- **Kernel & System Internals:** Understand kernel architecture, boot processes, and memory operations.

### Tech Stack
- **Frontend:** React, Vite
- **Backend:** Python, FastAPI
- **Concepts:** Operating Systems, Process Management, Memory Management, Synchronization

Install dependencies and follow the project setup instructions to run the frontend and backend.

### Purpose
Built to make operating system concepts easier to understand through practical, interactive simulations.
